Export

Secrets and private keys are never exported. The bundle holds environment placeholders, external KMS references and a manifest of the values the target environment or its secret manager supplies.

The archive (ZIP) also holds assets such as logos. The JSON bundle is easier to edit.

Import

An archive, a JSON bundle, or one configuration document as a resource download saves it. The plan is read-only and always comes first.
